# Netflix Content Analysis Dashboard — Tableau

## 📊 Project Overview

This project analyzes Netflix movies and TV shows using **Tableau**. The purpose of the project is to understand Netflix content distribution based on content type, genres, ratings, countries, and release-year trends.

An interactive Tableau project was created with **two dashboards** to present the analysis in a simple and easy-to-understand way.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze the distribution of Movies and TV Shows.
- Identify the top countries based on the number of titles.
- Identify the most common genres.
- Analyze content ratings.
- Analyze Netflix titles by release year.
- Understand how content has been added to Netflix over time.
- Compare Movies and TV Shows across different release years.
- Create interactive dashboards for easy data exploration.
